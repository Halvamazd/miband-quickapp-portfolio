# VOID · 腕上地脉

小米手环 9 Pro（Xiaomi Vela / QuickApp）上的交互小玩具：
**点击哪里，就在哪里长出一条随机的"地脉"** —— 从零生长（约 1.2~1.8 秒）后整体渐隐；同一时间只允许一条地脉在场。

> ⚠️ **测试品**：仅用于实验与演示，**不提供发行版**（无 Release 包）。请自行构建，或侧载自签名 debug 包。

## 玩法

- 屏幕中央显示"点击"提示文字，完成第一次点击后消失；
- 轻点任意位置：生出随机走向、分支与色调的地脉，并伴随一次短震反馈；
- 动画进行期间的新点击会被忽略（单动画互斥，保持画面干净）。

## 构建

- 依赖：`aiot-toolkit`（npm）
- 命令：

```bash
npm install
npm run build
```

产物：`dist/<package>.debug.<version>.rpk`（本作品包名为 `com.void.leyline`）。

## 侧载注意事项（真机）

- 零售版手环通常**只放行 debug 签名的安装包**，请使用 `npm run build` 的产物；
- 侧载前建议**强制停止官方手机端管理应用**（如"小米运动健康"），避免蓝牙通道被抢占（GATT 133）；
- 单只手环建议常驻第三方应用不超过 3~5 个，留意存储占用；
- 手环快应用无后台、内存紧张：息屏或切后台随时可能被回收，请保持应用"轻量"。

## 兼容性

- 目标设备：小米手环 9 Pro（336×480，Vela / HyperOS）；
- 其他 Vela / QuickApp 设备未测试。
