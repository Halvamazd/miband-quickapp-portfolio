# 彩灯 · Lantern

小米手环 9 Pro（Xiaomi Vela / QuickApp）上的小玩具：
**点到哪里，就从哪里亮起一盏灯** —— 光球弹入 → 短暂停顿 → 扩散铺满整屏，整个屏幕染成同一种颜色；再点一下，换一种颜色继续。

> **测试品**：本作品用于实验与演示，暂未发布发行版（Release）；可自行构建，或侧载自签名 debug 包。

## 玩法

- 打开即进入"手电筒模式"：**屏幕保持常亮、亮度拉满**（退出时自动恢复原来的亮度与模式）；
- 屏幕中央显示静态"点击"提示文字，完成第一次点击后消失；
- 轻点任意位置：从点击处弹出一颗彩色光球（起始直径约 40px，贴合手指接触感），短暂停顿后扩散铺满全屏，成为新的背景色；
- 颜色按黄金角跳跃（137.5° + 随机），保证相邻两次颜色差异明显；
- **屏幕铺满的瞬间即可再次点击换色**（动画进行中的其它点击会被忽略）；
- 每次触发都有短震反馈。

## 构建

- 依赖：`aiot-toolkit`（npm）
- 命令：

```bash
npm install
npm run build
```

产物：`dist/<package>.debug.<version>.rpk`（本作品包名为 `com.halvamazd.lantern`）。

## 侧载注意事项（真机）

- 零售版手环通常**只放行 debug 签名的安装包**，请使用 `npm run build` 的产物；
- 侧载前建议**强制停止官方手机端管理应用**（如"小米运动健康"），避免蓝牙通道被抢占（GATT 133）；
- 单只手环建议常驻第三方应用不超过 3~5 个，留意存储占用；
- 手环快应用无后台、内存紧张：息屏或切后台随时可能被回收，请保持应用"轻量"。

## 兼容性
