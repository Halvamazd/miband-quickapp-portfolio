# 彩灯 · Lantern

小米手环 9 Pro（Xiaomi Vela / QuickApp）上的小玩具：
**点到哪里，就从哪里亮起一盏灯** —— 光球弹入 → 短暂停顿 → 扩散铺满整屏，整个屏幕染成同一种颜色；再点一下，换一种颜色继续。

> **测试品**：本作品用于实验与演示，暂未发布发行版（Release）；可自行构建，或侧载自签名 debug 包。
> 包名：`com.halvamazd.lantern2`（自 v1.5 起更名，用于绕开设备端图标缓存）。

## 玩法

- 首次进入显示"点击"提示，点一次后不再出现；
- 轻点任意位置：光球从点击处弹出并扩散铺满全屏，成为新背景色（支持屏幕任意位置，包括最底部）；
- 颜色按黄金角跳跃（137.5° + 随机）；
- 铺满瞬间即可再次点击换色，每次触发短震反馈；
- **长按（约 0.6 秒）→ 设置**；设置/二级页**左滑返回**，返回主界面为黑屏，不再显示提示文字。

## 设置项

- **自定义颜色**（二级页占位）
- **屏幕亮度**（竖条滑块，系统手电筒风格；拖动松手生效）
- **屏幕常亮**（开关，**进入设置默认开启**，离开设置自动关闭）
- **关于彩灯**（卡片式：彩色标题、简介、版本、右侧应用图标、开发组与说明）

> 亮度 / 常亮仅在设置页内按需调用；离开设置自动关闭常亮，不做亮度恢复。

## 构建

```bash
npm install
npm run build
```

产物：`dist/com.halvamazd.lantern2.debug.1.5.0.rpk`。

## 侧载注意事项（真机）

- 使用 debug 签名包；桌面图标有缓存，建议**卸载旧包（com.halvamazd.lantern）后安装新包**；
- 侧载前建议**强制停止官方手机端管理应用**（如"小米运动健康"）；
- 单只手环建议常驻第三方应用不超过 3~5 个；RPK 控制在 50KB 以内。

## 兼容性

- ✅ 已验证设备：小米手环 9 Pro（336×480，Vela / HyperOS）；

- 🚫 **请勿在非目标设备与未测试设备上安装使用，后果自负**；
