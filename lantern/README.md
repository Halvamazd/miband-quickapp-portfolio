# 彩灯 · Lantern

小米手环 9 Pro（Xiaomi Vela / QuickApp）上的彩灯玩具：**点到哪里，就从哪里亮起一盏灯**。

> 包名：`com.halvamazd.lantern2`。
> 目标设备：小米手环 9 Pro（336×480，Vela / HyperOS）。

## 功能

- 轻点任意位置：光球扩散铺满全屏；连续点击有 250ms 防抖；
- 长按 800ms 进入设置；若已亮色，黑球自左下角扩散熄灭后进入；
- 设置/二级页返回：底部按钮或左滑；返回主界面保留原色；
- 提示文字在首次点击或进入设置后即消失。

## 设置

- **自定义颜色**：色环取色；中心圆为当前预览色，点击中心圆即确认并震动；颜色从预览圆位置生成光球铺满全屏；使用自定义颜色后自动开启"锁定当前颜色"。
- **锁定当前颜色**：开启后主界面点击只保留震动反馈，不切换颜色、不播放动画。
- **屏幕亮度**：竖条滑块，进入时读取系统当前亮度，松手后单次 `setValue`。
- **屏幕常亮**：默认开启，同时作用于主界面与设置页。
- **关于彩灯**：卡片式信息页，显示当前版本 1.7.2。

## 状态共享

跨页面状态存放在 `app.ux` 的 `data.lantern`，页面通过 `this.$app.$def.data.lantern` 读写。

## 手势与返回

- 非首页页面在 manifest 中声明 `followHand: disable`，并实现 `onBackPress`：先播放退出动画、动画完成后调用 `router.back()`，返回 `true` 以尝试接管系统返回；
- 若固件不支持该能力，系统按默认行为处理，不影响页面内的按钮/左滑返回。

## 侧载

- debug 签名包；图标有缓存，必要时卸载重装；
- 推包前强停"小米运动健康"（防 GATT 133）；
- RPK 控制在 50KB 以内。
