# 彩灯 · Lantern

小米手环 9 Pro（Xiaomi Vela / QuickApp）上的彩灯玩具：**点到哪里，就从哪里亮起一盏灯**。

> 包名：`com.halvamazd.lantern2`。
> 目标设备：小米手环 9 Pro（M2401B1，336×480，Xiaomi HyperOS 2.0 / Vela）。

## 功能

- 轻点任意位置：光球扩散铺满全屏；连续点击有 250ms 防抖；
- 长按 800ms 进入设置；若已亮色，黑球自左下角扩散熄灭后进入；
- 设置/二级页返回：底部按钮或左滑；色盘页仅限底部“返回”按钮；返回主界面保留原色；
- 提示文字为“点击/长按 屏幕”，首次点击或进入设置后消失。

## 设置

- **自定义颜色**：色环取色；中心圆为当前预览色，点击中心圆即确认并震动；颜色从预览圆位置生成光球铺满全屏；使用自定义颜色后自动开启“锁定当前颜色”。
- **锁定当前颜色**：开启后主界面点击只保留震动反馈，不切换颜色、不播放动画。
- **屏幕亮度**：竖条滑块，进入时读取系统当前亮度；松手时若系统为自动亮度，会先切换为手动模式再写入数值。
- **屏幕常亮**：默认开启，同时作用于主界面与设置页。
- **关于彩灯**：卡片式信息页，显示当前版本 1.7.4。

## 状态共享

跨页面状态存放在 `app.ux` 的 `data.lantern`，页面通过 `this.$app.$def.data.lantern` 读写。

## 手势与转场

- 非首页页面声明 `followHand: disable` 并实现 `onBackPress`：先播放退出动画、完成后调用路由返回；
- 所有页面在展示后的 380ms 内启用**转场输入锁**，忽略触摸与返回手势，避免动画与系统转场叠加造成错位；
- 色盘页完全拦截系统返回（`onBackPress` 直接消费），只能通过底部“返回”按钮调用 `back()` 退出。

## 构建

```bash
npm install
npm run build
```

产物：`dist/com.halvamazd.lantern2.debug.1.7.4.rpk`。

## 侧载

- debug 签名包；图标有缓存，必要时卸载重装；
- 推包前强停“小米运动健康”（防 GATT 133）；
- RPK 控制在 50KB 以内。

## 通用说明

- 当前构建方式为 `aiot build`（development 模式），产物使用 **debug 签名**，未启用 `aiot release` 正式签名。
- 目标设备（零售版）仅接受 debug 签名包；`aiot-toolkit` 自带的 debug 证书属于公共开发证书，仅用于侧载测试，不代表可信发行身份。
- GitHub Release 中提供的 RPK 均为**版本化 debug 包**，不等同于应用商店级正式发行。
- 正式签名方案暂不启用；若后续设备策略或分发条件变化，再评估切换。

## 实机情况

### 验证环境

- 设备：小米手环 9 Pro（M2401B1）
- 系统：Xiaomi HyperOS 2.0 / Vela
- 软件版本：1.3.153
- 屏幕：336×480 AMOLED
- 安装方式：debug 签名 RPK 侧载

### 已验证

- 触摸判定：短按、800ms 长按、连续点击防抖；
- 设置页入场/退场动画与二级页返回；
- 系统返回手势接管（`followHand: disable` + `onBackPress`）；
- 色环取色、中心圆确认、颜色球自预览圆扩散；
- 自动亮度下切换手动模式并写入亮度；
- 屏幕常亮与主界面状态保持；
- 转场输入锁（380ms）。

### 已知限制

- `@system.storage` 在该固件不可用；跨页状态仅运行期有效，结束进程后恢复默认（常亮开、锁定关、色相 0）。
- 亮度接口属系统敏感能力，仅在用户主动操作时单次调用。
- 色盘页为独立路由页，横向手势由 `onBackPress` 接管。
- 仅一台实机验证；其他 Vela 3.6+ 设备未实测，请勿随意安装。
