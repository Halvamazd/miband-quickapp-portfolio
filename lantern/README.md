# 彩灯 · Lantern

小米手环 9 Pro（Xiaomi Vela / QuickApp）小玩具：**点到哪里，就从哪里亮起一盏灯**。

> 测试品，暂不发布 Release。
> 包名：`com.halvamazd.lantern2`。

## 玩法

- 轻点任意位置：光球扩散铺满全屏；连续点击有 250ms 防抖；
- 长按 800ms 进入设置；若已亮色，黑球自左下角扩散熄灭后进入；
- 设置/二级页左滑返回；返回主界面保留原色；
- 首次进入的"点击"提示只出现一次。

## 设置

- **自定义颜色**：色环取色（拖动圆环选择色相），中心圆为当前预览色；**点击中心圆即确认并震动**，新颜色会从该圆位置生成光球扩散铺满全屏；页面底部为放大的"返回"按钮，不再使用左滑返回（避免转动色环时误触）。
- **锁定当前颜色**：开启后点击主界面只保留震动反馈，不切换颜色、不播放动画。
- **屏幕亮度**：竖条滑块，进入时读取系统当前亮度，松手后单次 `setValue`。
- **屏幕常亮**：默认开启，并同时作用于主界面与设置页。
- **关于彩灯**：卡片式信息页。

## 构建

```bash
npm install
npm run build
```

产物：`dist/com.halvamazd.lantern2.debug.1.6.1.rpk`。

## 侧载

- debug 签名包；图标有缓存，必要时卸载重装；
- 推包前强停"小米运动健康"（防 GATT 133）；
- RPK 控制在 50KB 以内。

## 兼容性

- ✅ 小米手环 9 Pro（336×480，Vela / HyperOS）实机验证；
- ⚠️ 其他 Vela 3.6+ 设备理论兼容、未实测；
- 🚫 勿在非目标设备安装，后果自负；
- 🧑‍💻 仅一台实机，全程移动端开发构建。
