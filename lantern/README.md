# 彩灯 · Lantern

小米手环 9 Pro（Xiaomi Vela / QuickApp）上的小玩具：
**点到哪里，就从哪里亮起一盏灯** —— 光球弹入 → 短暂停顿 → 扩散铺满整屏；再点一下，换一种颜色继续。

> **测试品**：实验与演示用途，暂不发布发行版（Release）。
> 包名：`com.halvamazd.lantern2`（自 v1.5 起更名，用于绕开设备端图标缓存）。

## 玩法

- 首次进入显示"点击"提示，点一次后消失且不再出现；
- 轻点（按压 <300ms）任意位置：光球扩散铺满全屏；
- 连续点击有 250ms 防抖；按压超过 650ms 才进入设置（底层触摸自行判定，不用系统 longpress）；
- **长按 → 设置**；若当前已亮色，黑球从左下角扩散覆盖全屏（熄灯效果）后进入设置；
- 设置/二级页：**左滑返回**；设置元素反向滑出，回到主界面时原色保留、不闪色。

## 设置项

- 自定义颜色（占位）
- 屏幕亮度（竖条滑块，松手生效）
- 屏幕常亮（默认开启，离开设置自动关闭）
- 关于彩灯（卡片式：彩虹标题、简介、版本、右侧应用图标；开发组与说明在卡片下方）

## 构建

```bash
npm install
npm run build
```

产物：`dist/com.halvamazd.lantern2.debug.1.5.1.rpk`。

## 侧载注意事项

- 使用 debug 签名包；图标有缓存，建议卸载旧包后安装；
- 侧载前强制停止"小米运动健康"（防 GATT 133）；
- RPK 控制在 50KB 以内。

## 兼容性

- ✅ 已验证：小米手环 9 Pro（336×480，Vela / HyperOS）；
- ⚠️ 其他 Vela 3.6+ 设备理论兼容，未实机验证；
- 🚫 **勿在非目标设备安装使用，后果自负**；
- 🧑‍💻 仅一台 9 Pro 实机，全程移动设备开发构建。
