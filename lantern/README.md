# 彩灯 · Lantern

小米手环 9 Pro（Xiaomi Vela / QuickApp）上的小玩具：
**点到哪里，就从哪里亮起一盏灯** —— 光球弹入 → 短暂停顿 → 扩散铺满整屏，整个屏幕染成同一种颜色；再点一下，换一种颜色继续。

> **测试品**：本作品用于实验与演示，暂未发布发行版（Release）；可自行构建，或侧载自签名 debug 包。

## 玩法

- 屏幕中央显示静态"点击"提示文字，完成第一次点击后消失；
- 轻点任意位置：从点击处弹出一颗彩色光球（起始直径约 40px），短暂停顿后扩散铺满全屏，成为新的背景色；
- 颜色按黄金角跳跃（137.5° + 随机），保证相邻两次颜色差异明显；
- 屏幕铺满的瞬间即可再次点击换色；每次触发均有短震反馈；
- **长按屏幕（约 0.6 秒）进入设置**（独立页面，走 router 页面栈）；
- **左滑返回**：设置/二级页 → 返回上一页；返回首页即回到初始"点击"界面。

## 设置项

- **自定义颜色**（二级页占位）：下个版本开发；
- **屏幕亮度**（二级页）：竖条滑块（同系统手电筒的交互），拖动松手后生效；退出应用不恢复系统原亮度；
- **屏幕常亮**：滑块开关；
- **关于**：版本号 1.4.0 与开发组 Halvamazd。

> ⚠️ 亮度 / 常亮接口按"仅手动触发、单方法调用"实现：启动时不调用任何亮度接口；只有你在设置里主动操作时才会发出**单次**请求。若固件不支持，界面会提示"接口不可用"，不会重试。

- **v1.4.0**：图标改为官方要求的 192×192（圆角 48）；页面改用 `@system.router` 页面栈（设置 / 亮度 / 关于 / 颜色独立页），返回手势不再误退出应用；亮度页重做为系统手电筒风格的竖条滑块；全站字号加大以符合手环视觉习惯；主界面扩散球限制最大半径并裁切，修复顶部渲染异常。

## 构建

- 依赖：`aiot-toolkit`（npm）
- 命令：

```bash
npm install
npm run build
```

产物：`dist/<package>.debug.<version>.rpk`（本作品包名为 `com.halvamazd.lantern`）。

## 侧载注意事项（真机）

- 零售版手环通常**只放行 debug 签名的安装包**，请使用 `npm run build` 的产物；
- 桌面图标有缓存：覆盖安装后若图标仍是旧版，请**卸载后重新安装**一次；
- 侧载前建议**强制停止官方手机端管理应用**（如"小米运动健康"），避免蓝牙通道被抢占（GATT 133）；
- 单只手环建议常驻第三方应用不超过 3~5 个；RPK 请控制在 50KB 以内。
