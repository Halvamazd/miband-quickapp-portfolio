# 彩灯 · Lantern

小米手环 9 Pro（Xiaomi Vela / QuickApp）上的彩灯玩具：**点到哪里，就从哪里亮起一盏灯**。

> 包名：`com.halvamazd.lantern2`。
> 目标设备：小米手环 9 Pro（336×480，Vela / HyperOS）。

## 功能

- 轻点任意位置：光球扩散铺满全屏；连续点击有 250ms 防抖；
- 长按 800ms 进入设置；若已亮色，黑球自左下角扩散熄灭后进入；
- 设置/二级页左滑返回；返回主界面保留原色；
- 首次进入的"点击"提示只出现一次。

## 设置

- **自定义颜色**：色环取色；中心圆为当前预览色，点击中心圆即确认并震动；颜色从预览圆位置生成光球铺满全屏；**使用自定义颜色后自动开启"锁定当前颜色"**；页面仅通过底部"返回"按钮离开，不响应左滑。
- **锁定当前颜色**：开启后主界面点击只保留震动反馈，不切换颜色、不播放动画。
- **屏幕亮度**：竖条滑块，进入时读取系统当前亮度，松手后单次 `setValue`。
- **屏幕常亮**：默认开启，同时作用于主界面与设置页。
- **关于彩灯**：卡片式信息页，显示当前版本 1.7.0。

## 状态共享

跨页面状态存放在 `app.ux` 的 `data.lantern`，页面通过 `this.$app.$def.data.lantern` 读写。不使用 `@system.storage`（该固件不可用）。

## 构建

```bash
npm install
npm run build
```

产物：`dist/com.halvamazd.lantern2.debug.1.7.0.rpk`。

## 侧载

- debug 签名包；图标有缓存，必要时卸载重装；
- 推包前强停"小米运动健康"（防 GATT 133）；
- RPK 控制在 50KB 以内。
