## 实机情况

### 验证环境

- 设备：小米手环 9 Pro（M2401B1）
- 系统：Xiaomi HyperOS 2.0 / Vela
- 软件版本：1.3.153

### 验证范围

- Lantern：已在上述设备完成实机验证，覆盖触摸判定、设置页、色盘取色、亮度、常亮、返回手势与转场。

- 其他机型：均未实机验证。

### 说明

- 仅一台实机；开发、构建、侧载均在移动端完成，适配结论以 9 Pro 实测为准。
- 固件差异可能导致接口行为不同，尤其是存储与亮度相关能力。

## 通用说明

- 手环快应用（QuickApp）需自行构建，依赖 `aiot-toolkit`；本仓库当前使用 `aiot build`（development 模式），产物为 **debug 签名包**，未启用 `aiot release` 正式签名。
- 目标设备（零售版）仅接受 debug 签名包；`aiot-toolkit` 自带的 debug 证书属于公共开发证书，仅用于侧载测试，不代表可信发行身份。
- GitHub Release 中提供的 RPK 均为**版本化 debug 包**，不等同于应用商店级正式发行。
- 正式签名方案暂不启用；若后续设备策略或分发条件变化，再评估切换。
- 仓库代码默认以 [MIT 许可证](./LICENSE) 开源，如作品内另有说明则以作品说明为准。
