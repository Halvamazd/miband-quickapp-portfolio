*A portfolio of Xiaomi Mi Band QuickApps (Vela) — code and notes, growing over time.*

## 收录说明

- 本仓库收录小米手环 / Vela 平台的 QuickApp 小创作，作品成熟度不一；
- **发行版（Release）仅面向成熟作品**：成熟作品发布后可在 Releases 页获取；未成熟的作品暂不发布发行版。

## 通用说明

- 各作品的使用方式与注意事项，见其各自目录内的 `README.md`；
- 仓库代码默认以 [MIT 许可证](./LICENSE) 开源，如作品内另有说明则以作品说明为准；
- 手环快应用（QuickApp）需自行构建（依赖 `aiot-toolkit`），并以 **debug 签名包**侧载到设备。
